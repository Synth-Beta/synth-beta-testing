# charles-polish
<!-- text-only -->

Takes an interface that already works and makes it feel finished, level by level.

```bash
npx skills add LemonFace0309/charles-skills --skill charles-polish
```

Add `-g` to install it for every project, or copy this folder into `~/.claude/skills/` (Claude Code) or
`~/.agents/skills/` (Codex).

## What it does

- Fixes the details people feel: states, hit areas, contrast, layout shift and type
- Makes the motion correct, and checks every animation frame by frame
- Works in levels, so each pass leaves the screen better than the last

## Try it

```text
/charles-polish this login page
/charles-polish the checkout flow, then verify the motion frame by frame
/charles-polish review the settings screen without changing anything
```

## Pairs with

[charles-unslop](../charles-unslop/) first if the screen still looks AI-made, and
[charles-ux-animation](../../drops/charles-ux-animation/) for how things move and respond.
