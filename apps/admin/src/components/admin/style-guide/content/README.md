# Synth Skills Bundle

Internal Synth knowledge pack for humans and AI agents.

## Contents

| Folder | Use |
|--------|-----|
| `synth-brand/` | Colors, type, logo, voice, CSS/Tailwind tokens |
| `synth-product/` | Mission, history, team, product, data overview |
| `synth-ai-dev-guide/` | How agents should work on Synth |

## Install

1. Download from https://styleguide.getsynth.app (admin login required)
2. Unzip into `.cursor/skills/` or `.agents/skills/`
3. Or paste `llms-full.txt` into your agent context

## Authority

Live site: styleguide.getsynth.app  
Access: Supabase Auth + `users.account_type = admin`
